# Contributing

1. Use Node.js 22 or a currently supported LTS release.
2. Create a branch and keep changes focused.
3. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`,
   `npm run test:desktop`, and `npm run build:desktop`.
4. Never commit secrets, user projects, generated media, FFmpeg binaries, or AI
   model files without verified redistribution rights.

By contributing, you agree that your contribution is licensed under Apache-2.0.
