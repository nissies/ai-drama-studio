# Security Policy

Please report vulnerabilities privately to `www02212022@163.com` or through
GitHub's private vulnerability reporting feature. Do not include API keys,
access tokens, private project files, or personal information in a public issue.

User-supplied model API keys are encrypted with Electron `safeStorage` and kept
on the current Windows device. The application does not ship with model keys.
Only connect the client to AI endpoints and optional backends that you trust.
